# Sprites esperados

Coloca tus sprites en esta carpeta con estos nombres para que el juego los use automáticamente:

- `naruto.png` (sprite sheet del jugador, idealmente en grilla 6x5)
- `enemy_ninja.png` (sprite sheet enemigo, idealmente en grilla 5x7)

Si faltan, el juego usa render fallback (formas básicas) para que siga funcionando.
